# 🎲 Genshin Gacha Optimizer

📐 [Архитектура и логика проекта](ARCHITECTURE.md)

Monte Carlo симуляция баннера персонажей Genshin Impact — сколько розыгрышей и примогемов реально понадобится, с учётом pity и правила 50/50.

Это не ML-модель: вероятности гачи официально известны, задача — честно посчитать распределение исходов через симуляцию, а не предсказывать что-то неизвестное.

## Возможности

- Ввод текущего pity и статуса гарантии (выиграл/проиграл прошлый 50/50)
- Медиана, среднее и 90%-й перцентиль числа розыгрышей до цели
- Распределение исходов на гистограмме
- Вероятность успеть за заданное число розыгрышей

## Механика (встроена в симуляцию)

- Базовый шанс 5★ — 0.6% за розыгрыш
- Мягкая гарантия с 74-го розыгрыша, жёсткая — на 90-м
- Правило 50/50: первый 5★ — 50% шанс на баннерного персонажа, иначе следующий 5★ гарантированно баннерный

## Стек

- NumPy — Monte Carlo симуляция (20 000 прогонов)
- Streamlit — интерфейс
- Plotly — гистограмма распределения

## Запуск

```bash
git clone https://github.com/whyalohadance/genshin-gacha-optimizer.git
cd genshin-gacha-optimizer
pip install -r requirements.txt
streamlit run app.py
```
